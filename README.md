# 🛍️ Shrii Store

Shrii Store is a Django-based e-commerce website developed as a learning project and CodeAlpha task.

## 📌 About the Project

Shrii Store provides a simple online shopping experience where users can browse products, view product details, add products to their cart, and place orders.

## ✨ Features

- 🏠 Home page
- 🛍️ Product listing
- 🔎 Product details
- 🛒 Add to cart
- 📦 Cart management
- 💳 Checkout
- 🧾 Order placement
- 👤 User login and registration
- 📋 View orders
- 🖼️ Product images
- 📊 Product stock management

## 🛠️ Technologies Used

- Python
- Django
- HTML
- CSS
- SQLite
- Bootstrap
